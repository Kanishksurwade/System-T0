# Day 2: Reality Check & UI Wireframing

Today was a challenging day. I thought designing the UI and lock screen would be easy, but I had to navigate strict App Store and Play Store guidelines. 

**What I did:**
* Learned that continuous animations on a lock screen will get the app rejected (battery drain). 
* Pivoted to a "state-based" static widget design (similar to Duolingo). The warrior sprite will simply update its pose when a task is checked.
* Finalized the monetization plan: 100% free offline tier, with skippable ads inside the main app to recover my developer fees.
* Spent hours researching tools (v0.dev, Cursor, Figma, Mobbin).
* Created the first rough UI sketches (Goals screen, Profile, and Widget layout) in Canva to use as a base for AI generation tomorrow.
