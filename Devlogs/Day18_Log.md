**Project:** System: T-0

## What We Did
- Reviewed practical iOS widget concepts and learned about WidgetKit, shared storage, refresh limitations and using sample data during development.
- Decided to finish the in-app Widgets screen before attempting native home-screen or Lock Screen widgets.
- Kept the product direction focused: minimal RPG identity, simple enough for anyone to use, without overloading the app with features.

## Next Steps
1. Build the in-app Widgets screen using the existing app design.
2. Connect its content to real Calendar and Profile data—avoid a separate task system.
3. Prioritise a Daily Tasks widget, followed by a Streak & Character widget.
4. Consider a day-end countdown later, after validating the first widgets.

## Platform Decision
Development is currently on Windows with Expo and React Native. Native iOS widget compilation, signing and final testing will require access to macOS/Xcode or a suitable cloud Mac workflow. We will investigate the Expo-compatible implementation when the in-app screen is ready.
